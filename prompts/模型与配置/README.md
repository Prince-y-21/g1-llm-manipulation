# 模型与配置：清单、证据与准入状态

库版本：`2026-10-20.1`。本目录为文档资料库的一部分，**不是机器人可执行配置或已验证模型包**。当前只收录状态清单；尚未把旧代码、URDF、网格或标定结果复制为可运行工具。

[本机配置与验证状态.json](本机配置与验证状态.json)用于查找历史线索和暴露缺口。`execution_ready=false`与`runtime_state.current=false`明确说明它不能用于自动批准运动。不得将JSON中历史节点、网络、温度或硬件描述直接当作当前状态。

`execution_ready`、`completed_for_new_task`等字段仅表达本库描述性状态与检查模板，不是切换为true就能获得的运动许可。每次准备是否完成及其证据另存本次run记录，不回填长期资料库的实时字段；真正可复用的验证成果另记适用范围、日期与证据。

## 1. 文件用途与优先关系

1. 当前任务授权和现场实证决定动作范围。
2. 当前有效模型、当前实时反馈和本次准备验证支持规划。
3. 本目录清单负责指向这些资料并说明证据级别。
4. 历史实验文件只用于追溯，不自动覆盖本次结果。

需要理解参数时阅读[硬件与接口](../01_本机硬件与控制接口.md)、[几何与标定](../02_机器人与夹爪几何模型及标定.md)，操作按[执行与恢复](../03_执行流程与异常恢复.md)；不要从清单推断隐含运动授权。

## 2. 将来应纳入的资产

| 资产 | 最低内容 | 当前状态 |
|---|---|---|
| 本机装配模型 | G1、Dex1、转接件、腕相机、导轨/夹指、必要附件 | 未完成统一实物验证；没有现成可执行包 |

| 控制配置版本 | 接口、单位、范围、增益/前馈、限幅、状态机和恢复 | 旧实验存在不同版本，尚未作为通用控制器认证 |

文件不齐时先完成能够独立开展的读取、模型审查和离线计算；关键资产缺失时补取、补测或缩小任务，不能猜测尺寸或继续使用未验证的包络。历史复盘本身不是执行所需的关键资产。

## 3. 新资产记录格式

每项至少记录以下字段，文件使用库内相对路径并附哈希：

```text
asset_id / version / status / source_type / checked_at
local_path / sha256 / hardware_variant / applicable_conditions
parent_frame / child_frame / units / transform_direction
coverage / exclusions / uncertainty / validation_method
validation_evidence / independent_test_results / invalidation_triggers
```

状态应区分`historical_observed`、`manufacturer_reference_pending_local_verification`、`approximate`、`unverified`和`requires_current_check`。只有完成对应范围的实物验证后才可另记`validated_for_scope`，同时写清范围；不能把一个动作成功扩展成整机、全部开度和所有负载都已验证。

模型URDF必须核对依赖网格、坐标与单位；附图片而无尺度不能证明覆盖。可视化通过不代表碰撞引擎使用了同一几何。标定记录应包含独立测试；只给优化残差或训练样本误差不充分。

## 4. 维护边界

- 可以记录SSH别名、设备序列号和非敏感路径；不复制密码、私钥、令牌或完整SSH认证配置。
- 本资料库默认在本机维护，部署代码/日志到服务器需要单独说明；文档不默认上传。
- 旧任务绝对关节目标、临时跳过温度检查版本、遗留release文件不收为常用配置。
- 新控制工具先审查副作用、路径、互斥和恢复，再决定纳入；代码原目录现阶段保持不变。
- 实验结束后更新稳定事实与未解问题，保留历史证据；实时姿态、电量和模式留在当次运行记录。
- 单文件导出汇总文档和清单；不能声称导出文字同时包含了完整模型、驱动或标定数据。

旧工作区可能存在基础URDF及实验工具，可以按主文档中的可选线索取得。资料库被移动到另一台电脑后，本目录也能说明缺什么；它不依赖原用户绝对路径才能理解。
