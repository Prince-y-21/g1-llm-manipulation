# 公开版机器人任务资料库

这里是历史资料库的公开化副本。个人路径、具体硬件标识、私网地址和主机指纹已替换；这些占位信息不能用于识别你自己的设备，也不是已验证的活动配置。

从[任务入口](00_任务入口提示词.md)开始，按需阅读[接口](01_本机硬件与控制接口.md)、[几何与标定](02_机器人与夹爪几何模型及标定.md)、[执行与恢复](03_执行流程与异常恢复.md)，填写[任务模板](04_任务模板与成功判据.md)。配置说明见[模型与配置](模型与配置/README.md)，独立全文见[完整提示词](导出/G1机器人完整提示词.md)。

资料保留历史经验与验证缺口。历史机器人状态、序列号占位和目标角度不替代本次实时检查。源文件与生成全文的关系可由本目录脚本重新生成并校验；只做本地文档处理。

```powershell
& './生成完整提示词.ps1'
& './校验资料库.ps1'
```

发布版的[维护说明](维护记录.md)记录公开化差异。token统计的本地PowerShell工具保留，原始会话日志和实际用量记录不随包分发，不能据此默认获得其他用户的日志。
