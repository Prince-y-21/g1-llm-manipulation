# G1 LLM Manipulation

基于大模型的宇树G1桌面操作研究工程：控制代码、提示词资料库、实验示例、执行证据和demo。

## 控制分工

GPT分析任务与观测、生成或修改候选计划及程序；Python进行几何/运动学计算、检查与阶段编排；C++持续读取反馈、插值/保持并发送身体或夹爪指令。执行反馈回到后续判断。大模型不是逐个电机周期调用，具体控制器的活动关节和全身保持需按版本核对。

本仓库首版为研究源码和实验快照，保留历史代码的任务耦合、近似模型及未验证项，尚未统一为通用运行时。修改个人路径与设备标识的公开副本不等同于重新通过了实机测试。

## 实验结果

- 抓瓶与放回：完成小幅试提、放回及撤回。
- 搬瓶至鼠标垫：完成搬运、松开、水瓶独立直立与机械臂回到起始附近；图像未见其他物体明显移动，不据此声称全过程零接触。
- A4纸搬运：一轮完成夹起、搬运、松开、正常退出，纸只部分搭在垫上，精准放置未完成。
- 倒水与拧盖：未完成实际倾倒或旋开；公开准备、空载验证、失败与恢复经验。

[水瓶4×演示](demos/bottle_to_mousepad/demo_4x.mp4)为3分56秒，剪去观察/等待；[A4纸4×演示](demos/paper_partial_placement/demo_4x.mp4)为83秒，保留部分放置的真实结果。成片时间不等于原始实验耗时。
