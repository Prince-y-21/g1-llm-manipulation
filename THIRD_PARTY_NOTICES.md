# Sources and third-party materials

The root MIT license covers original project contributions. It does not grant new rights to manufacturer SDKs or other third-party materials. Original demonstration clips and posters are included as project documentation under MIT.

Referenced but not bundled: Unitree G1 SDK2 and DDS bindings; the Unitree motor SDK used by Dex1-1; Intel librealsense; OpenCV; NumPy/SciPy/Pillow; optional Pinocchio, MuJoCo and geometry tools used by individual historical planners. Install each under its own license and check the required platform/version.

Manufacturer URDFs, CAD meshes, vendor binaries, downloaded papers, third-party screenshots, original long recordings, private SSH material and original conversation logs are excluded. Historical source uses vendor APIs and concepts; this repository does not claim ownership of those APIs or robot designs.

Control-source provenance is documented in `source_provenance.csv`: original source hash, public-copy hash and whether transformations occurred. The public copy is distinct from the historically executed binary/source version.
