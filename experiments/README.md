# Selected experiment evidence

## Bottle to mousepad, October 16–17, 2026

Completed transport, upright independent release, withdrawal and return near the initial posture. The included `bottle_to_mousepad/evidence/` files contain a 114-command historical audit and final result summary. They are observation/audit data, not active trajectory defaults. The source snapshot includes different development versions; use provenance and the recorded task context to distinguish them.

The video shows the task progression. Absence of visible object displacement does not establish zero contact throughout the path. Approximate geometry and visual/depth uncertainty remain relevant even when a specific run completed.

## Paper partial placement, October 25, 2026

The later source snapshot corresponds to a run that grasped, transported and released A4 paper, returned near its takeover posture and exited normally. The paper was only partly supported by the mousepad, with substantial overhang. This is partial placement success, not the complete target outcome. The demonstration retains that result.

## Uncompleted tasks

Pouring and cap opening are included as development code and operational experience. The archived pouring attempt did not perform actual pouring; cap-opening work reached limited unloaded bimanual/gripper validation without manipulating the cap. They are not presented as completed skills.

Full conversation histories, original long videos, original server binaries and all continuous sensor logs are not part of this curated release. A selected static evidence package is not a complete training dataset or a time-synchronized action-observation benchmark.
